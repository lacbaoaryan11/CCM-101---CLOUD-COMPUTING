# Laboratory Activity 05: The Cloud Data Engineer

## Mission Overview

In this laboratory activity, I learned about different types of cloud storage and deployed a MinIO object storage server using Docker. MinIO is an S3-compatible storage system that can store files such as images, videos, and backups.

I used the KillerCoda Playground to run MinIO inside a Docker container. I also accessed the MinIO Web Console, created a bucket named `client-photos`, and uploaded a sample file.

## Objectives

At the end of this laboratory activity, I was able to:

- Differentiate between Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Use Docker environment variables.
- Access a cloud service using a web browser.
- Create an object storage bucket.
- Upload a file to a bucket.
- Document cloud storage operations using Markdown.
- Practice using the Linux command line.
