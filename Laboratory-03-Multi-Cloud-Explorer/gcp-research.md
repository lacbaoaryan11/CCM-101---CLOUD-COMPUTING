# Google Cloud Platform (GCP)

## 1. Brief Overview

Google Cloud is Google's cloud computing platform. It provides services for computing, storage, databases, networking, artificial intelligence, analytics, and application development.

## 2. Global Infrastructure

Google Cloud operates a global infrastructure consisting of regions and zones that allow customers to deploy applications and services around the world.

## 3. Cloud Management Console

The Google Cloud Console is a web-based interface for managing Google Cloud resources and services.

## 4. Four Core Services

### Compute Engine
Provides virtual machines.

### Cloud Storage
Provides object storage.

### Virtual Private Cloud
Provides networking capabilities.

### Google Kubernetes Engine
Provides managed Kubernetes infrastructure.

## 5. Three Advantages

1. Strong AI and machine learning capabilities.
2. Strong Kubernetes technology.
3. Global infrastructure.

## 6. Typical Enterprise Use Cases

Google Cloud can be used for artificial intelligence, machine learning, analytics, web applications, data processing, and containerized applications.
